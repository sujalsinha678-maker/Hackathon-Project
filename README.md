# AI-Powered Title Uniqueness System

An AI-powered system that uses NLP-based semantic similarity to compare newly proposed titles with existing records, generate similarity scores, and identify potentially duplicate or highly similar titles.

## Key Features
- NLP-based semantic similarity analysis
- Compares new titles with existing records
- Generates similarity scores
- Helps identify duplicate or highly similar titles

## Team
Developed as a hackathon project by a 5-member team, Team Hex Syndicate.
